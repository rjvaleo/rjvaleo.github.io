M-Clone

M let you compose by steering processes instead of writing notes. I rebuilt it for the browser from its manual alone, and shipped a free alpha four days after the first commit.

The problem

  • M's way of composing, with variables, cyclic patterns, conducting and snapshots, has no modern equivalent in a browser.
  • It had to be faithful without copying a line of the original.
  • Composers needed real MIDI out, to hardware and to their DAW.

What I did

  • Ran it as a clean room: the M 2.7 manual decides behavior, screenshots decide only layout.
  • Turned the manual into 180 numbered capabilities, each one a test. 163 pass and 17 are exclusions with a reason, checked on every build.
  • Cut features on purpose and said so: MIDI file import stays out “unless a future workflow creates real user value”.
  • Merged 34 contradictory planning docs into one master plan with decisions of record.
  • Split the 5,711-line engine into its own library with no browser code, so it can ship as a plugin and run inside idMLab.
  • Ran a three-stage AI design review: clipped controls went from 17 to 0, and title contrast from 3.7:1 to over 5.6:1.

What changed

  • v0.8.0-alpha shipped as a single HTML file that opens with no install.
  • Live MIDI in, recording and a sixteen-channel matrix.
  • The engine now runs as a module inside idMLab.
