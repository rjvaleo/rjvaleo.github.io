How I use AI

The full method

To run the program

  • Requirements: every contract requirement traced to its epics, designs, rules and tests. Links the tool inferred stay marked as inferred.
  • Planning: one board for five increments. A gate with no data shows a dash, never green.
  • Reporting: delivery reports and roadshow numbers rebuilt from exports, and reconciled before anyone presents them.
  • People: I am the AI resource for the program’s business analysts.

To guide the build

  • I decide what to make and what to cut, and write it down before any code.
  • Tests are the referee, not the model’s word. A 180-item manual became 180 tests.
  • Agents work inside written rules: scope, git limits, and the lesson from each time one overreached.
  • I check the agents’ numbers. A reported 682 tests turned out to be 384.
