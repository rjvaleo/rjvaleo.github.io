Scale Sequencer

A step sequencer with true-pitch tuning and a full synth voice, built on the Web Audio API with no framework and no build step.

The problem

  • Scales and tunings outside twelve-tone equal temperament are hard to play from a piano roll.

What I did

  • Built the sequencer: per-step degree, octave and rest, forward, reverse, ping-pong and random.
  • Modeled true pulse-width modulation with 256-harmonic Fourier synthesis.
  • Wrote a tempo-synced ping-pong delay and a stable cathedral-scale reverb from scratch.
  • Drew live canvases for the envelopes, LFOs and delay path.

What changed

  • Runs offline and deploys to GitHub Pages.
