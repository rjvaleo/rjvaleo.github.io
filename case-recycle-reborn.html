Recycle Reborn

Drop in a drum loop and it finds every hit, slices it, and exports the slices as a ZIP, all in your browser.

The problem

  • Slicing a loop into hits by hand is slow.

What I did

  • Wrote the README as a functional spec first: loading, silence detection, waveform, playback, loop tails, export, stats and interface.
  • Built the silence-detection engine and the waveform view on Web Audio and Canvas.
  • Added loop-tail synthesis and ZIP export.
  • Added twelve built-in sounds, synthesized in the page, and tuned the drum loops dry so they slice cleanly. It opens with a funk break already cut into 16 slices.

What changed

  • A working slicer that runs from a single file.
  • Nothing to download before you can try it.
